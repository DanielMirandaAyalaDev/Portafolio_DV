# Documentación de portafolio

## Paleta de colores

### Fondos

- **#080D20** Color del fondo
- **#203A78** Color de la barra de navegación
- **#3A5BFF** Color para resaltar
- **#15234A** Azul oscuro
- **#55BFFF** Cyan
- **#D9E5FF** Textos
- **#C7D5EE** Pale Silver

## Tipografías

- **Cormorant Garamond** Tipografía para los títulos grandes, como tu nombre y los encabezados de sección.
- **Inter** Párrafos, botones, navegación, descripciones de proyectos y habilidades.
- **JetBrains Mono** Etiquetas pequeñas, fragmentos de código, números de proyectos y detalles decorativos.
